# Android Areas
While every type of task is important we have categorized some of the areas based on the effort we want to put into implemention.

You can treat those areas as a guideline for when you have more than one task idea and want to decide on the order.

### Core
- Jetpack Compose
- Coroutines and Flows
- Build/Gradle
- Networking: OkHttp / Retrofit
- Breaking Android SDK changes
- Kilo
### Essential
- Material
- Performance
- KMP
- Navigation
- Image loading: Coil / Glide
- Security & Privacy
- Edge to Edge
- Media: Media3 / ExoPlayer

### Other
- WebView
- Intelligent Apps
- Foldables
- Form Factors
- Health
- Stores / Play
- Vulkan
