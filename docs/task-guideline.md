# AI use while task creation
Our goal is to evaluate the performance of language models on these tasks. Overzealous use of coding assistants by human domain experts may produce tasks that are artificially easy for those models.

- Task descriptions must be hand-written.
- Tests and solutions can be created using agentic tools, but you must thoroughly review the output.
- Tasks that have been obviously fully generated by an LLM will be rejected because it is clear an LLM can already do this task.

> [!NOTE]
> If you're using an LLM agent to implement the solution, in general, the more back-and-forth you have to do with the agent implementing the task, the better.
